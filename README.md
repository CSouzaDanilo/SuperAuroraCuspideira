
# Descrição

O "Super Aurora Cuspideira" é um projeto pessoal feito com ajuda da I.A. ChatGPT e muito carinho de um Papai apaixonado pela filha, que está na fase de cuspir. <br>
Então por que não fazer um jogo onde o poder principal é o cuspe?


# Controles

**Pular:** Tecla Z 

**Cuspir:** Tecla C

**Frente:** Seta Dir 

**Trás:** Seta Esq
