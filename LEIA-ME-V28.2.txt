FLUXO DE EDIÇÃO:
1. Execute um servidor HTTP na pasta do jogo: python3 -m http.server 8000
2. Acesse http://localhost:8000/editor.html
3. Escolha a fase, edite e clique SALVAR RASCUNHO.
4. TESTAR FASE abre a fase com seu rascunho local.
5. Clique EXPORTAR JSON; o nome baixado é fase-1-N.json.
6. Substitua o arquivo de mesmo nome em fases/ no seu repositório.
7. Faça git add fases/ && git commit -m "Atualiza fases" && git push.
8. index.html passa a carregar os JSONs publicados, independentemente do navegador.

IMPORTANTE: o navegador não grava automaticamente na pasta do projeto.
Os rascunhos locais continuam sendo locais. Em caso de falha HTTP,
o jogo recorre ao mapa padrão/rascunho local. Para evitar resultados
inconsistentes, abra via HTTP e não pelo protocolo file://.

A V28.2 não altera a geometria nem implementa câmera vertical.
